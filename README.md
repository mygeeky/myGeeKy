<table>
<tr>
<td width="20%" align="center" valign="middle">

</td>
<td valign="middle">

> *“You haven't used Nextflow yet — and five repos near your work just did. Shall we start?”*

**Any skill becomes a road map.** *R for data analysis* turns into: R basics → statistics with R → a real
project to rerun → your own work. A level check **skips what you already know**, using your own repos as
evidence (*“6 of your repos use R”* — which you can overrule).

For a skill nobody has written up, a small model **on your machine** (about 400 KB) searches code and papers
and sorts what it finds into stages. **14 protocols are written and reviewed**, from *your first pull request*
to *statistics for experiments: which test, and why*.

## 🎯 Helps you catch the opportunities while they are still open

<table>
<tr>
<td width="20%" align="center" valign="middle">
  <img src="https://raw.githubusercontent.com/mygeeky/myGeeKy/main/docs/geekoc/geekoc-chances.png" width="160" alt="GeekOc pointing">
</td>
<td valign="middle">

> *“Two deadlines this week. Both still open — I checked the page myself.”*

**Jobs, funding, conferences and the scholarships that come back every year.** Each one is **checked against its
own page** before you see it, sorted by **deadline**, and **gone the moment it passes** — so the board is never
a list of things you are already too late for.

A listing written in **Arabic, French, German, Spanish or Chinese** is read, translated and still checked against
its own page, then shown to you in English. Filter by country, because that applies to all of them.

**And 🗓 Seasons, for the ones that come back every year.** A scholarship does not stop being real when it
closes — it returns next April, and *the preparing takes longer than the applying*. So myGeeKy says
*“expected in about 12 weeks”* while there is still time to get transcripts certified and a proposal written,
and tells you **how many years of evidence** stand behind that expectation. It never pretends to know next
year's date: a window it read on a page says **open now**, anything ahead says **expected**.

## 🚀 Try it

<table>
<tr>
<td width="50%" valign="top">

### 🪟 Windows

1. Download **[MyGeeKySetup.exe](https://github.com/mygeeky/myGeeKy/releases/latest)** (under *Assets*)
2. **Next → Next → Finish**

Nothing needs installing first — it sets up Python and Git for you, no admin rights.

<sub>If Windows says <i>“Windows protected your PC”</i> (not code-signed yet): <b>More info → Run anyway</b>.</sub>

</td>
<td width="50%" valign="top">

### 🐧 Linux · 🍎 macOS · 🐍 anywhere

```bash
curl -fsSL https://mygeeky.org/install.sh | sh
```

or with pip:

```bash
pip install mygeeky
mygeeky setup
```

<sub>Run the one-liner again to update. Macs get <b>myGeeKy.app</b> in Launchpad and Spotlight.</sub>

</tr>

## 🔒 What it will never do

> *“I keep all of this on your computer. I never post for you, and I never tell anyone you were here.”*

- ✋ **Never acts as you.** It never follows, stars, forks, posts or comments — **there is no code for it
  anywhere in the project.** You look, you decide, you act.
- 🧠 **Never leaves your machine.** The model that ranks all of this runs on your computer, because there is
  no server. No account, no sign-up, no telemetry.
- 🔑 **Never holds your keys.** Tokens live in your operating system's keyring, checked for least privilege,
  **never logged and never printed.**
- 📦 **Never takes your data.** It stays on your computer — plus a **private repo you own**, if you want sync.
- 📨 **Never sends anything behind your back.** If it breaks, you read the whole report first — your name,
  email, tokens and folders already stripped out — and **you** decide whether it goes.

<sub><a href="https://github.com/mygeeky/myGeeKy/blob/main/docs/GUIDE.md#safety">Safety in full</a> ·
